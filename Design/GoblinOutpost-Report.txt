GOBLIN OUTPOST AND QUARRY REVISION
Updated: 8 November 2026
Scene: Assets/Scenes/SampleScene.unity

RESULT
The northeast outpost is integrated into the existing scene. Its entry branches north from the existing east road. The latest requested raised quarry grass/cliff stage was removed and replaced with a ground-level, timber-framed mine entrance, rails, a loaded cart, rock deposits, a native wooden workbench and a reachable loot chest.
Chest opening animation was added afterward; see Design/Chest-Animation-Report.txt for those changes and tests.

INSPECTION
The original main Grid has 1x1 cells. HiddenPondClearing also contains 0.25-cell collision/bridge grids, which were left alone. Existing sorting layers are Default, Background, Ground, Objects and Foreground; transparency uses the Y axis. Existing art uses 64 PPU for Tiny Swords and 32 PPU for Pixel Crawler/Cute Fantasy, with Point filtering and uncompressed textures. The outpost follows these existing pack-specific settings and the existing 2D-lit material. Full inspection: Design/Outpost-Inspection.txt.

CREATED CONTENT
- EnvironmentExpansion/GoblinOutpost with GoblinCamp, Ruins, Quarry, Barricades, Chests, Trees, SpawnPoints and Tilemaps reference groups.
- Central timber fence enclosure with a south-facing opening, three red shelters, animated campfire, two gate banners/torches, cooking pot/tripod and weapon display.
- Northeast stone watchtower with red banner and an orc lookout visual.
- Northwest ruins with arch, pillars, blocks, a central stone marker and chest.
- Southwest pond with shore detail, foliage and fallen wood.
- Southeast ground-level mine with workbench, cart, rails, rubble and crystal decorations. The previous new Quarry Ridge and Quarry Ledge tilemap objects/colliders were removed at the user's request; unused tile assets were retained.
- Three timber road stakes, clustered trees, flowers, shrubs and rocks.
- Six new overlay tilemaps under Grid/Tilemaps/GoblinOutpost Tilemaps so they share the original Grid. Original ground and water tiles were not overwritten.
- Three actual LootChest prefab instances under EnvironmentExpansion/LootChestInstances. Outpost/Chests has their named location markers.
- Seven enemy layout markers: five in camp, one quarry marker and one tower marker. Six ground markers register with the existing enemy spawner; the tower marker is excluded from ground AI.
- Reusable prefabs for the red shelter, fence segment, barricade stake and four tree variants.

GAMEPLAY INTEGRATION
- Solid fences, stakes, structures, rocks, trunks, ruins and pond boundaries have Collider2D components. Walkable ground, paths and flowers have no blocking collider.
- Existing LootChest reward/interaction logic is reused.
- Added Assets/Scripts/Environment/GoblinOutpostReferences.cs to retain scene references and register/unregister the ground spawn markers.
- With explicit user approval, EnemySpawner.cs accepts optional registered scene points. Each existing spawn attempt has a 25% chance to try one; original wave budget, active cap, player-distance, walkability, safe-zone and route checks still apply. No second spawner or extra enemy budget was added.
- Decoration has no new idle per-frame behavior scripts; campfire animation uses an animation clip/controller.

PRESERVATION AND BACKUPS
Initial scene, detailed transform/component/tile snapshot, script hashes and importer backups are in Design/Backups/GoblinOutpost.
Before the later chest work, comparison of 57,679 original records found only the 50 permitted original scattered rocks disabled for the new area's footprints/routes. Their objects were retained; exact paths are in Outpost-DisabledOverlappingRocks.txt. Original tiles, Player, Canvas and camera setup matched that snapshot.
Later live Editor edits are also present: the latest comparison includes six other original environment transform differences (Camp/Lookout, Rocky Region_6 and Trees 01/02/34/36), alongside the two intentionally updated original LootChest components. Those separate live edits were not reverted. Accordingly, the final scene should not be described as byte-for-byte unchanged outside the outpost.
The latest object/margin audit reflects the live scene, including subsequent edits; two collider roots no longer satisfy its conservative two-cell margin (Mine Bank Boulder_02 and Palisade_20). They were not repositioned during the chest-animation task.

REFERENCE DIFFERENCES / LIMITS
- Available packs did not contain the exact reference tents or spiked palisade. Red Tiny Swords shelters and existing timber fences/posts are used instead.
- The central ruins marker substitutes for the reference rune monument.
- The tower lookout is a visual prop, not a functioning ranged goblin archer. Night waves use the existing enemy archetypes and shared AI.
- The quarry marker participates in night spawning; it does not add a permanent daytime patrol route.
- Mine entrance, ore crystals, workbench, pot and rack are scenery. No mine interior, new harvesting nodes or new crafting system was introduced.
- The mine replaces the raised quarry ridge because the user explicitly requested removal of that stage.
- No manual Inspector setup is required for the implemented systems.
