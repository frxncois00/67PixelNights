PHASE 5 — INVENTORY & ITEM SYSTEM
Implemented and validated in Unity 6000.6.4f1 on 2026-11-06.

A. IMPLEMENTATION SUMMARY
Implemented directly in Assets/Scenes/SampleScene.unity.
20 main slots in a 4 x 5 grid and 5 bottom-centered hotbar slots share one authoritative InventoryController.
Four ScriptableObject definitions provide stable IDs, names, descriptions, icons, categories, stack limits and equip/drop rules.
Resources stack to 99. The non-stackable Basic Axe starts in hotbar slot 1 and cannot be dropped through item management.
Supported operations include add, all-or-nothing add, quantity/capacity queries, consume across stacks, move, swap, merge, split, equip, unequip, drop one and drop stack.
Click-based selection leaves items in their slots. Closing the inventory cannot strand a cursor-held item.
Partial pickups retain overflow in the world. Full pickups display INVENTORY FULL and remain collectible.
The inventory blocks movement and world actions while open. Day/night and campfire fuel continue.
No hunger, combat, crafting, save/load or other later-phase systems were added.

E. INVENTORY ARCHITECTURE
InventoryController owns 25 runtime slots. Indices 0-19 are the main inventory; 20-24 are the hotbar.
Slot contents have public read-only accessors. Mutations validate quantities and indices.
Adding fills existing stacks before empty main slots and then empty hotbar slots.
TryAdd rejects the whole transaction if capacity is insufficient. Add returns the accepted quantity.
Remove checks total holdings before consuming across stacks. Move merges or swaps without quantity duplication.
Split moves half into the first available slot and rejects safely when none is free.
The UI keeps a selected slot index rather than extracting a stack into temporary storage.
Changed events refresh the inventory, equipment, wallet facade and resource totals.
Item assets use stable IDs basic_axe, wood_log, stone and scrap. Definitions are canonical catalog assets.

A separate pickaxe inventory item was not added in this phase.

I. CONTROLS AND UI
WASD / arrows — movement
Space / left-click — axe chopping when the Basic Axe is selected
R — existing pickaxe mining when the tool is equipped
E — nearest contextual pickup, scrap, refuel or relight
U — campfire upgrade
Tab / I — toggle inventory
Escape — close inventory
1-5 — select hotbar slot during gameplay
G — drop one from the selected droppable hotbar stack
Left-click a stack then another slot — move, merge or swap
Click the selected slot again — deselect
Right-click a stack — split half into a free slot
Drop One / Drop Stack — drop selected resource quantities
Close button — close and release modal input

The user explicitly chose to restore Space/click rather than retain E chopping.
Number-key selection is suppressed while typing in the project's Unity UI InputField or while the inventory is open.
The fixed detail panel shows item name, description, category and quantity/maximum without extending off screen.
Existing pickup and campfire messages are reused; new inventory notifications cover equipment and drop actions.

The pickaxe has no separate inventory item yet.

Items are session-local and reset when restarting Play Mode. No persistent save system was added.
Legacy ResourceNode world-drop placement still uses its existing bounded search; its earlier warning behavior when no space exists was outside this inventory change.
The tooltip is a fixed inventory detail panel, not a floating cursor-following tooltip.

M. MANUAL ACCEPTANCE
No Inspector setup or code changes are required.
1. Open Assets/Scenes/SampleScene.unity and press Play. Focus Game view.
2. Confirm slot 1 shows the axe and all resource counts are zero.
3. Press Tab, I and Escape. Check opening/closing and that movement stops only while open.
4. Press 2 to select an empty slot. Try Space/click and R near a node. Re-select 1 and confirm the appropriate tool animation works.
5. Chop a tree with Space/click, then E near its drops. Use R near a mineable rock.
6. Open inventory. Click a stack and an empty slot, swap two different types, right-click to split, hover/select to inspect details.
7. Drop one or the whole selected resource stack. Close inventory and recollect with E.
8. At the campfire, E refuels/relights and U upgrades using the displayed inventory wood.
9. While inventory is open, try E/U/Space/R and watch the day timer and fuel continue.
10. Check ordinary movement, tree/house collision, camera following and animations.
11. Check the UI at the three target resolutions, then stop Play. Runtime test quantities are not saved.
