E–J. TERRAIN, REGIONS AND PATHS
The original Ground Tilemap was extended so existing drops, wildlife, player
systems and enemies share one terrain authority. Existing grass/path/water assets
are reused with unchanged import settings. EnvironmentExpansion groups new art.
North: Dense Forest, center (0,20), resource trees/berries/stumps.
East: Rocky Region, center (27,0), mineable/decorative rocks and scrap.
South: Abandoned Cabin, center (0,-20), copied existing building art, loot cache.
West: Dark Forest, center (-27,0), tinted new foliage, limited supplies and cache.
Three-unit dirt routes lead outward; broad ground infill connects the regions.
Initial pass added 1,344 ground cells and 25 resource nodes; subsequent infill
and 517 varied tree/rock placements create the final continuous forest.
Some new trees/rocks are permanent decoration; others reuse ResourceNode health,
yield and regrowth. Existing original objects were not regrouped.
The cabin is an exterior existing-house reuse, not an enterable interior.

K. WORLD BOUNDARIES
Small BoxCollider2D segments border exposed Ground cell edges. No giant blocking
collider spans playable terrain. Connected cells have no separating boundary.
Direct physical player edge traversal remains UNVERIFIED; collision-aware grid
reachability passed for the region routes.

L–M. NAVIGATION AND SPAWNING
ForestNavigation: configurable .5-unit cardinal grid; static-collider footprint
checks plus Ground samples; no diagonal corner cutting. Bounded breadth-first
search (default 12,000 expansions); one-second cell-cache expiry reflects runtime
resource changes. Enemies reuse routes for .8 seconds and validate actual steps.
Spawn candidates must connect to the player's terrain component. Connectivity
checks ignore safety only for region membership; enemy movement avoids active
protection. No extra spawner, cycle or difficulty manager.
Relight/upgrade retreat searches an unprotected location; a still-protected,
trapped enemy is safely dismissed after 12 seconds, with a warning. It is never
teleported through geometry. See Phase7-Hardening-Report.txt.

N–O. LOOT AND INVENTORY
Two separate caches at (2,-20) and (-25,0); reusable LootChest prefab.
Uses InteractionTarget and existing E handler. Rewards roll once, pending counts
remain on the chest, and InventoryController.Add determines accepted quantities.
Partial/full inventory never discards remainder. Empty caches cannot reroll.
Current rewards: existing wood 2–5, stone 1–4, berries 1–3, scrap 1–3.
Inspector reward entries allow other existing items; no item definitions added.
Lid rotates on opening, empty cache dims; received items use existing message UI.
Visual is an explicitly named wooden-cache placeholder built from existing log
sprites, not finished chest artwork. State is session-only, reset by scene load.

P. DISCOVERY

Rectangular spatial regions checked in fixed order; unique HashSet prevents
